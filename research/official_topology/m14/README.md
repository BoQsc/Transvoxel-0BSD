# M14 M4 Replacement-Readiness Gate

M14 converts the accumulated M4 evidence into a machine-readable replacement
decision.

It distinguishes:

```text
optional M4 transition-backend candidate readiness
readiness to replace the default transition backend
functional full Transvoxel.cpp replacement readiness
exact table/encoding compatibility readiness
```

Run:

```text
RUN_M14.cmd
```

The expected result is currently a successful analysis with the replacement
decision blocked. Runtime/integration evidence passes, while official topology,
reference convention, all-six-face M4 production proof, junction proof, regular
cell equivalence, and consumer compatibility remain unproven.
