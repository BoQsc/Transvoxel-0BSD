# Stage 06 — interactive sandbox

Purpose: personal evaluation of the terrain behavior after the non-visual proof gate passes.

This stage is intentionally separate from the Godot proof stages. It is where the terrain can be flown around, edited, inspected, and judged by feel.

Godot files live in:

```text
godot/stages/06_interactive_sandbox/
```

Run from Windows with:

```text
RUN_INTERACTIVE.cmd
```

This stage writes optional logs to:

```text
godot/validation/06_interactive_sandbox/session.json
```
